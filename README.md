# Thanuja_protfolio

Personal portfolio website for **Thanuja K N** — Software Engineer & Electronics and Communication Engineering student at Adichunchanagiri Institute of Technology (AIT).

## 🌿 Features
- **Scenic Nature Aesthetics**: Photorealistic lush forest background with atmospheric contrast overlay.
- **Dynamic 60 FPS Fluttering Butterflies**: Custom HTML5 Canvas physics engine with 5 distinct butterfly species, realistic 3D wing flapping, and pollen sparkle trails.
- **Top Navigation Bar**: Sticky frosted glass navigation with live ScrollSpy and mobile drawer.
- **Theme Switcher**: Day (Sunlight ☀️) and Night (Twilight 🌙) modes with system preference detection.
- **Projects**:
  - 🛡️ *Women’s Safety & Monitoring* (3 Months)
  - 🔋 *Charging and Monitoring* (3 Months)
  - 🌿 *Nature Portfolio Application*
- **Skills**: Python, C, Data Structures, Modern HTML5/CSS3, JavaScript, IoT, and Microcontrollers.
- **Responsive Layout**: Fluid typography with `clamp()` and fine-tuned breakpoints for desktop, tablet, and mobile.

## 🛠️ Tech Stack
- **HTML5** Semantic Architecture
- **Vanilla CSS3** (Custom Properties, Glassmorphism, CSS Grid & Flexbox)
- **Vanilla JavaScript** (Canvas Animation, Event Handlers, LocalStorage)
